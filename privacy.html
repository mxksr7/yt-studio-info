Datenschutzerklärung

Stand: 24. November 2026

Welche Daten

yt-studio greift ausschließlich lesend über die YouTube Data API, die YouTube Analytics API und die YouTube Reporting API auf die YouTube-Kanäle zu, die der Betreiber selbst besitzt und ausdrücklich verbunden hat. Abgerufen werden Kanal- und Videoangaben (Titel, Veröffentlichungszeit, Status) sowie zusammengefasste Statistiken (z. B. Aufrufe, Wiedergabezeit, Abonnenten, Impressionen, Klickrate).

Wofür

Die Daten werden nur genutzt, um sie dem Betreiber in seinem eigenen Dashboard anzuzeigen. Es findet keine Werbung, kein Profiling und kein Verkauf von Daten statt.

Speicherung und Weitergabe

Die Daten werden in einer privaten Datenbank des Betreibers gespeichert. Zugangs-Tokens liegen verschlüsselt vor. Daten werden nicht an Dritte weitergegeben.

Widerruf und Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Danach werden keine Daten mehr abgerufen; gespeicherte Daten werden auf Wunsch gelöscht.

Die Nutzung von YouTube-Daten unterliegt den YouTube-Nutzungsbedingungen und der Google-Datenschutzerklärung.
